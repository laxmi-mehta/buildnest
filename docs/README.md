## What is BuildNest?

**Plan. Build. Track.** BuildNest is the complete digital workspace for homeowners to plan, organize, track, document and manage the entire home construction journey — budgets, expenses, materials, contractors, documents, photos, timelines, tasks, milestones and reports in one place.

## Current phase

Foundation only. The repository contains production-grade scaffolding — design system, component library, layouts, routing, auth screens, dashboard pages with realistic dummy data, API abstraction layer — with **no business logic, no real API implementations and no database models** yet.
