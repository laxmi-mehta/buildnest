# BuildNest

> **Plan. Build. Track.** — The complete digital workspace for homeowners managing a construction project.

BuildNest gives homeowners a single place to manage budgets, contractors, tasks, documents, and site photos throughout the entire home construction journey.

---

## Features

### Dashboard

A live overview of the active project — budget burn, upcoming milestones, recent expenses, open tasks, and contractor headcount.

### Projects

Create and manage multiple construction projects. Each project is an isolated workspace; switching projects updates every view instantly.

### Budget

Set a total budget and track spend against it. A cumulative spend chart shows the burn curve over time. Alerts surface automatically when spend exceeds 90% or the project goes over budget.

### Expenses

Log every site expense with amount, category, vendor, date, and payment method. The expense table supports search and filtering with a full category breakdown.

### Tasks

Manage the full task list for a project — create tasks with title, status (To Do / In Progress / Done / Blocked), priority (Low / Medium / High / Urgent), and due date.

### Milestones

Define key project milestones with target dates and track completion. Overdue milestones surface as alerts in Notifications.

### Timeline

A phase-by-phase project timeline built from milestone data. Shows overall project progress and a project history log.

### Analytics

Charts covering spend trends by week, expense breakdown by category, contractor spend distribution, and task throughput over time.

### Materials

Track materials ordered for the project — name, quantity, unit cost, supplier, and delivery status (Required / Ordered / Delivered / Installed).

### Contractors

A directory of all contractors on the project — name, trade, company, phone, email, and contract amount. Feeds the Dashboard headcount card.

### Documents

Upload and manage project documents — permits, contracts, invoices, plans, and reports. Each document can be downloaded or deleted. Storage usage and document count shown as stat cards.

### Photos

Upload site progress photos from any device. Photos are displayed in a responsive grid grouped by upload month. Clicking any photo opens a full-screen lightbox with caption and date.

### Notifications

Real-time alerts for overdue tasks, delayed milestones, and budget warnings. Badge count shown in the navigation.

### Settings

- **Profile** — edit name; changes persist immediately.
- **General** — rename the project and update its address.
- **Appearance** — light / dark / system theme toggle.
- **Help** — FAQ and contact support.
